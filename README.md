# HES Asia | Healthcare Planning, Procurement & Management

A polished, portfolio-ready corporate landing page for HES Asia, a healthcare consultancy and solutions partner focused on planning, procurement, and management services across the healthcare sector.

## Overview

This project is a static business website designed to present HES Asia as a trusted healthcare partner in Malaysia and across the region. It highlights the company’s service offerings, project portfolio, client trust, certifications, and contact information in a premium, professional format.

## Purpose

The website is intended to:
- Showcase HES Asia’s healthcare consultancy capabilities
- Build trust with institutional healthcare clients
- Present project exposure and operational credibility
- Provide clear service and engagement pathways for inquiries
- Function as a portfolio/project demo for presentation or client-facing use

## Features

- Premium healthcare-themed landing page
- Responsive layout for desktop and mobile
- Fixed navigation and smooth in-page scrolling
- Service highlight panels
- Portfolio/project card grid with modal details
- Client and brand trust sections
- Certifications and company registration showcases
- Contact and WhatsApp call-to-action areas
- PDF preview modal for company credentials
- Lead capture form interaction
- Accessible keyboard interaction for modal and cards

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Static asset-based frontend design

## Local Setup

1. Clone the repository:
```bash
git clone https://github.com/esfahanjones/Hesa_mockup_3.git
```

2. Open the project folder:
```bash
cd Hesa_mockup_3
```

3. Launch the site locally:
- Open `index.html` in a browser, or
- Run a local static server in the project directory

Example:
```bash
python -m http.server 8000
```

Then visit:
```bash
http://localhost:8000
```

## Deployment

This project is a static website and can be deployed on:
- GitHub Pages
- Netlify
- Vercel
- Traditional web hosting
- Any PHP-enabled server for the lead form backend

## Notes

- The website includes a lead capture flow connected to `send-lead.php`.
